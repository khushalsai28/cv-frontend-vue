# Contributing to CircuitVerse Vue Frontend

Thank you for contributing to cv-frontend-vue.

We follow the fork -> clone -> branch -> edit -> pull request workflow.

## Prerequisites

- Node.js >= 18
- npm >= 9
- Git with SSH configured

## Getting Started

### 1. Fork the repository

Fork [khushalsai28/cv-frontend-vue](https://github.com/khushalsai28/cv-frontend-vue) on GitHub.

### 2. Clone your fork

```bash
git clone git@github.com:<your-username>/cv-frontend-vue.git
cd cv-frontend-vue
```

### 3. Create a branch

```bash
git switch -c your-new-branch-name
```

### 4. Install dependencies

```bash
npm install
npm run dev
```

### 5. Make changes and commit

```bash
git add CONTRIBUTING.md
git commit -m "Add your-name to Contributors list"
```

### 6. Push and open a Pull Request

```bash
git push -u origin your-branch-name
```

Then click Compare and pull request on GitHub.

## Code Style

- Vue 3 Composition API with script setup
- TypeScript strict mode
- Pinia for state management
